PyCurl-Lite in the browser

A web version of the Homework 01 command-line client. Type a curl-style command, using the same flags as pycurl_lite.py, and it runs through the browser's fetch().

Supported flags and browser limits

Supported: -X -H -d -u -I -i -L -v -s --max-time.

Not possible here: -F -o -O -b -k -A. Browsers block custom User-Agent and Cookie headers, file saving and certificate overrides.

The target server must allow cross-origin requests (CORS), as httpbin.org does. If it doesn't, the browser reports a network error. Use the Python CLI for those URLs, and see the README for install steps.
